# Fortran Source

The audited ORCHIDEE Fortran source is scientific truth but is not included in
the public Git candidate until its redistribution terms are confirmed.

For local Oracle regeneration, place the source checkout at:

```text
fortran_source/ORCHIDEE/
```

The directory is ignored by Git. Existing source hashes and line spans under
`docs/source_audits/` remain tracked as provenance evidence.
