# SECHIBA PFT14 Branch Micro-Case Matrix

Scope: source-driven branch ledger for SECHIBA-side branches that can affect
PFT14 mangrove runs when changing land point, forcing, or continuous
parameters. This is the SECHIBA companion to
`stomate_branch_microcase_matrix.md`; it is not a long-run validation result.

## Rules

1. Long paper-case runs are validation gates only. They are not branch
   discovery tools.
2. A branch is `PFT14 active` when the current paper run enters it.
3. A branch is `PFT14 conditional` when a different land point, forcing,
   state, or supported switch can enter it while still running mangrove/PFT14
   carbon-water processes.
4. A branch is `Non-PFT14 natural trigger` when it belongs to unrelated
   processes such as crop, grassland management, or ordinary fire.
5. Missing branch support must stay explicit through a guard, missing-field
   report, or documented micro-case backlog. Do not silently approximate.

   branch/state work changes a carried field.

   ledgers and micro-cases:

     HYDROL-facing adapter and broader HYDROL module assembly when all
     ENERBIL/THERMOSOIL/driver boundary inputs are supplied explicitly.

     dispatch, and CONDVEG scalar snow-cover handoff are source-covered for
     `OK_EXPLICITSNOW=n`; THERMOSOIL no-explicit-snow handoff is locally
     source-covered through the old thermix snow path and first-step wrapper
     dispatch.

     LD_DOC scenarios become target workflows; the next routing gaps are
     production NetCDF/`aggregate_p` wiring and complete routing-map asset
     availability for the day-sequence routing-flow wrapper.

   fire, or methane unless the research scope explicitly expands.
