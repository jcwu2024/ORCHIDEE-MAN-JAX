# STOMATE Branch Micro-Case Matrix

Scope: source-driven validation plan for STOMATE branches not proven by the
active paper-case PFT14 path. This file is a test-design ledger, not a closure
claim.

## Rules

1. Each micro-case toggles the smallest Fortran branch condition needed to
   enter the target process.
2. Each case validates local process outputs and restart/day-end state
   writeback, not a long annual trajectory.
3. A branch is not considered covered merely because a long run did not fail.
4. Every case must cite the Fortran file/subroutine/line span that owns the
   branch.

## Matrix

Priority classes used below:

- `PFT14 active`: active in the current paper-case PFT14 run.
- `PFT14 conditional`: still a mangrove/peat/redox/DOC/soil/restart branch, but
  requires a configuration switch or forcing/grid state outside the current
  paper case.
- `Non-PFT14 natural trigger`: not expected to activate merely by changing
  forcing, grid, or continuous PFT14 parameters; keep guarded, but do not spend
  near-term porting effort unless the research scope expands.
