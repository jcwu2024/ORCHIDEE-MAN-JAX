# 简化日尺度神经算子：架构与长期目标联合设计

日期：2026-09-21。状态：用户已同意实施；正在实现并做本地/免费节点验收，尚无科学精度结论。

用户要求先把架构整理成简洁、可解释、有依据的方法；讨论后已批准继续搭建。
本稿取代“立即申请旧架构 fresh-litter 1000 次更新”的当前工作顺序；
不改变已完成实验的事实，不删除旧实现、权重、数据或证据。
旧的 24.80 元付费提案搁置，不自动转成新架构的训练授权。

## 1. 需要回答的科学问题

同一个日算子在持续使用自己的预测状态时，能否保持 GPP、NPP、呼吸的
累计量和季节/年际变化，以及 AGB、BGB 等生物量轨迹，而不持续漂移？
单日拟合、梯度正确、运行完成和记账闭合都是必要证据，但不是这个问题的答案。

简化架构的理由是降低方法复杂度、权重继承依赖和解释成本，并集中学习能力；
没有证据证明“简化本身必然提升准确率”。本稿不是新模型成功的声明。

## 2. 已核实的事实与不能作出的推断

| 事实 | 对设计的约束 |
| --- | --- |
| 当前共 109,464,375 个神经参数；建网入口依次添加 maintenance、structured GPP、carbon feedback、conditioning | 重新声明一个完整架构；不再把继承链作为建网方法的叙述 |
| 当前多日损失已有逐日/累计 GPP、NPP、RA、RH，以及 AGB/BGB/冠层碳库存轨迹与终点 | 不能声称过去完全没训练长期相关目标，也不能把这些已有项重新命名为创新 |
| 当前 recurrent `STOCK_KEYS` 只有 AGB、BGB、冠层碳；凋落物、DOC、颗粒碳没有直接多日项 | 对碳库变化实行明确的逐类监督，而不是让库存大、坐标多的变量淹没其他变量 |
| 已完成四组续训均出现最终 T30 生产力/生物量误差高于共同起点 | 小窗口或个别碳库改善不等于整体成功；不能自动续训，也不能据此证明所有 fresh 方法失败 |

具体负结果：旧 checkpoint4000 的 16 个日样本中，地上凋落物每天移除约 19%，
Teacher 约 0.002–0.003%；这个发现支持审查输出尺度和监督，不能推广成所有
碳库、所有地点的确定机制。对应报告保留原始采样范围。

## 3. 架构原则：共享学习能力，保留物理语义

继续使用唯一日转换边界：

```text
canonical_assembler
  -> 有字段/坐标/掩码的输入表示
  -> 共享 Transformer
  -> 轻量、坐标共享的过程读出
  -> 已声明的物理因子与约束变换
  -> canonical conservative updater
  -> canonical retained-tail adapter
  -> 下一日物理状态
```

通过 `bind_daily_operator(input_assembler=canonical_assembler,
process_head=candidate_head, retained_tail=canonical_retained_tail_adapter)` 接入。
不引入跨日神经隐藏状态；日间记忆仍由显式物理状态承担。

“共享”指共享神经权重和统一计算规则，不代表所有参数、字段都可以互相访问。
保留 source ownership、PFT permutation equivariance、inactive/undefined masks、
土层/碳池/器官坐标、局部输入对齐；不能先无约束混合，再在最后一层加掩码。
`vcmax25` 和维护呼吸参数的显式物理路由继续保留，`alloc_min`、
`residence_time` 仍交给 retained exact 过程，不偷偷进入共享神经编码器。
GPP/呼吸显式参数因子之外的 state dependence 仍需可微，不能切断状态梯度。

| 现有部分 | 建议去向 | 保留的能力或理由 |
| --- | --- | --- |
| canonical assembler、状态/轴语义、原生 forcing | 保留数据边界，整理编码实现 | 仍用前驱记录及当天四个原生六小时记录；不重建 48 步 |
| 多套 process-expert、science/category 深层网络 | 合并到共享 Transformer 参数族 | 过程区别通过输入/输出字段和合法信息路由表达 |
| 约 975 万参数的呼吸专用 Attention | 用共享表示加轻量读出替代 | 仍按 PFT/器官输出环境修正，保留呼吸物理公式 |
| 约 1288 万参数的 structured GPP 分支 | 用共享表示加非负 GPP 响应读出替代 | “潜力×限制×修正”的拆分是建模假设，不是必须照搬的物理恒等式 |
| 约 308 万参数的额外碳反馈 Attention | 将所需碳状态接入主干的合法输入表示 | 删除独立神经模块，不删除碳状态及其跨日反馈 |
| 16 个 GPP 专用 temperature 参数 | 不再保留专用路径 | 统一明确 Q/K 与 attention-score 数值策略；不恢复已知不稳定的分数尺度 |
| 输出约束、离散状态/状态翻转语义、source-backed 边界 | 保留并显式列出 | 不负库存、不偷换 undefined、不把离散状态当普通浮点回归 |
| 已验证的 native JAX AD、公共 rollout、科学量 extractor | 复用 | 新损失/新网络做有针对性的梯度及更新验收，不重开所有历史 AD 工作 |

原模型 161 个 learned 字段包含 39,006 个标量坐标，其中主科学直接输出
26、状态必要输出 3,682、辅助监督 35,298。字段数不等于输出标量数。
第一版不因“只关心碳”而随意删除水热或辅助字段：沿用已审计的输出合同，
以共享的轻量坐标读出生成它们。辅助字段不参与推理的裁剪只有在消费者审计后
才能另行声明。不能对 39,006 个输出做全连接自注意力。

### 一套具体的首选拓扑

独立源码审查后的建议是共享参数的、带来源掩码的 Transformer cross-attention。
它使用常见的 attention + FFN + residual/normalization 构件；不声称某篇论文
已经证明这一具体组合适用于 ORCHIDEE。固定首选工程配置如下，不展开宽度搜索：

| 层次 | 建议配置 | 数据如何经过它 |
| --- | --- | --- |
| 输入 | 复用规范 forcing 编码、字段/轴表、数值条件化 | 保存原生时间顺序、defined/mask、字段和坐标；物理参数走明确路由 |
| 共享主干 | 8 个 block；width 768；8 heads；FFN 3072 | 七个过程查询流读取各自合法的 source/axis bank；七流共用每一层权重，八层之间不绑权 |
| 共享坐标解码器 | 2 个 block；同样 768/8/3072 | 输出字段/坐标查询读取所属过程表示和合法的局部/原始坐标 bank；所有输出使用同一套解码器权重 |
| 轻量读出 | 按物理输出类别的小型线性/MLP 投影 | GPP 响应、呼吸修正、库存变化参数、水热项等；无专属深层 Attention 堆栈 |
| 固定物理变换 | 非负/有界/显式参数因子/适用性 | 形成既有 typed process prediction，进入 updater 和 retained tail |

七流不做无约束的全局 self-attention：共享权重不等于共享所有输入。
字段读取主干/其他流的权限必须有来源闭包证明，否则信息可能通过中间表示绕过掩码。
GPP 的碳库信息仍以原始坐标 token 接入通用解码器，复用现有同 PFT/global-PFT
路由；删除的是那套专用学习权重，不是这条必要的信息路径。呼吸仍逐 PFT/器官
解码，不能先汇成一个总量再分配。

Attention 统一采用 FP32 分数和归一化 Q/K，实现明确为每个 head 的 Q/K 单位 L2
归一化，`logits = cosine(Q,K) * sqrt(head_width)`（768/8=96），即固定逆温度，
不添加专用温度参数。其他残差/归一化细节沿用可复用标准构件，
在实现合同固定，不从旧 checkpoint 继承。物理计算的精度边界保持已验收策略。

现有布局证据是 393 个 source token 加 140 个 factorized axis token；
GPP 原始碳状态是 107 个字段、2,386 个坐标。这些是当前布局，不是新实现的实测值。
393 个汇总 token 可能丢失字段内部关联，因此坐标局部状态和原始碳 bank 不能
仅以七个过程向量代替。输出按字段/固定 query chunk 计算，不构造 39,006²
的 attention 矩阵；chunk 仅是执行分块，不切断对应梯度。

仅十个标准 block 的主要矩阵，按 `10 * 12 * 768^2` 估算约 7,078 万参数；
还需 forcing 编码、embedding、读出、偏置等，故不能把此数写成准确总数。
这避免一边简化拓扑、一边把容量突然压到几百万。目的不是凑整或设置 6000 万上限。
共享权重不保证计算量减少：同一权重处理七流仍需要计算，坐标解码也可能成为瓶颈。
搭建前先落实 tensor-shape 表；搭建后才能给出准确参数量、token 数、显存和速度。

### 输出中心与初始化也是方法的一部分

保留库存 `x_next = x_start * (1-q) + incoming` 的已接受边界和有界 q。
建议对 outgoing 的 logit 使用 TRAIN 统计确定的字段中心及小残差初始化，
避免把 50% 日移除率作为所有库存的默认中心。非负 incoming 同样使用
TRAIN 中心和尺度；近零项需要数值下限及有效梯度检查。
这只改变学习坐标/初始化，不把库存直接交给无约束网络，也不声称识别了真实转移。
不能硬置所有 q=0、停掉碳变化或用大量 incoming 抵消 outgoing 来伪造稳定。
精确中心、下限和逆变换在实现合同中冻结；现阶段不编造未经统计的数值。

## 4. 长期目标如何落实到损失

建议整理为三个等权、各自先归一化的组：日过程、碳通量、碳库变化。
不沿用每修一个症状就永久追加一项特调权重的方式。

科学层必须从模型自己的连续 rollout 得到，窗口内不每天重置 Teacher 状态。
预测与 Teacher 从同一初始状态出发；比较 stock change 与比较 stock level 的
分子此时相同，重要区别在归一化尺度和是否报告变化方向，不应包装成两份新信息。

| 组 | 损失关注 | 同时报告/验收 |
| --- | --- | --- |
| 碳通量 | 逐日形状、窗口累计量和分段累计量；独立基底 GPP、维持呼吸、增长呼吸、RH | GPP、两类自养呼吸、RA、NPP、RH；单独检验 NPP，禁止靠错误抵消过关 |
| 活体生物量（碳库组） | AGB/BGB 逐日变化及相对初始状态的变化轨迹 | 库存水平、增长量、变化方向、季节/年际幅度 |
| 非活体碳（碳库组） | 冠层、地上/地下凋落物、DOC、颗粒碳分别的逐日变化和变化轨迹 | 各库和总量；禁止正负偏差相抵后只报总碳 |

NPP=GPP-RA、RA=维持呼吸+增长呼吸是相关目标。用独立通量作为基础拟合项，
NPP 单列科学验收；若需要 NPP 直接损失，必须预先给出其净收支权重，并说明
这是有意强调净通量，不能把派生量当额外独立观测堆叠。RH 为零的样本不能
证明非零 RH 拟合；先核实 TRAIN/开发集的激活覆盖，保留缺失覆盖声明。

损失建议的数学形式（本稿提出固定组权重；实际 TRAIN 尺度值仍待冻结）：

```text
loss = mean(process_day, flux_group, stock_group)
flux_group  = mean(flux_daily_batch, flux_T7, flux_T30)
stock_group = mean(stock_daily_batch, stock_T7, stock_T30)

e_f(t) = predicted_flux(t) - teacher_flux(t)
r_s(t) = [predicted_stock(t) - common_initial_stock]
         - [teacher_stock(t) - common_initial_stock]
r_s(0) = 0

flux_H = mean_fields_days(0.5 * rho(e_f(t)/s_f)
                       + 0.5 * rho(sum_{i=1..t} e_f(i)/(s_f*sqrt(t))))
stock_H = mean_fields_days(0.5 * rho((r_s(t)-r_s(t-1))/s_delta)
                        + 0.5 * rho(r_s(t)/(s_delta*sqrt(t))))
rho(z) = sqrt(1+z*z)-1
```

日样本的科学项按 H=1 计算。process_day 内将必要过程监督与分组日状态变化
监督各占一半，沿用来源、状态定义和掩码，不以巨大 standing stock 归一化。
离散状态的有定义损失保持其既定分类语义，不强行使用连续 pseudo-Huber。
碳库组中活体与非活体子组各占一半，然后组内按科学量等权平均有效项，避免
五个非活体字段仅凭个数压过 AGB/BGB。碳通量使用四个独立分量分别平均。
保留逐样本/逐窗口残差，不能先跨地点求均值再平方。

`s_f` 为实际抽取后物理通量的 TRAIN RMS，`s_delta` 为实际抽取后日库存变化
的 TRAIN RMS，均加有物理单位的近零下限。不是把许多原始列的标准差简单平方
求和，也不是使用庞大的 standing stock。使用固定、代表不同状态的 TRAIN
选择，冻结统计、近零下限和样本身份；验证/测试不参与尺度或权重拟合。
保存每组原始量、尺度、标量及梯度贡献，检查组等权是否仍有病态数值主导。
等权是可解释的首个设计选择，不是保证各组梯度相等的定理；未通过数值验收应
退回说明具体原因，不能在一次训练中悄悄调整权重。
不继承旧 checkpoint 标定的 5.221716892123007e-5 作为新方法的已证最优值。

现有 `_cumulative_term` 除以 `H * daily_scale`，库存轨迹项除以
`elapsed * daily_change_scale`。因此同样的每日系统偏差，即使累计误差增大，
归一化误差也可能保持不变。这不是梯度 bug。这里明确采用 `sqrt(t)` 权重，
使持续同号误差在归一化后仍随时间增长，同时保留逐日变化约束。
例如每日恒偏 b，旧累计残差是 b/s；新前缀残差是 b*sqrt(t)/s。
这是惩罚相干漂移的工程设计，不是假设真实模型误差独立同分布的证据，也不保证
长窗口一定更易优化。逐前缀项同时限制“前半段偏高、后半段偏低”的终点抵消。
终点已经包含在轨迹中，不再叠加一个独立 endpoint 权重。
pseudo-Huber 对极端值较稳健，但最差窗口/p95/变化方向仍须独立验收，不能被弱化。

累计项要求有效连续前缀；日变化要求前后两天均有效。定义内非有限预测计为失败，
不能悄悄删出 loss。已有保留过程导致的 source-defined 状态转换按合同处理。
合成测试先检查恒定漂移、正负交替、不同碳库抵消、近零目标与掩码，确认这个
损失确实惩罚我们声称要解决的问题，再做真实模型梯度/更新。

## 5. 训练与验收的有限决策路径

正式方法从一份声明的随机初始化和 fresh optimizer 开始，所有神经权重参与更新。
不继承探索 checkpoint；不要求随机初始模型已经拟合准确。
仍使用 v6 TRAIN、既有 split、可重放采样及多样本容器文件，不重新生产教师数据。

| 阶段 | 必须得到的答案 | 不满足时 |
| --- | --- | --- |
| 本次设计讨论 | 模块去留、信息路由、输出尺度和长期目标是否形成一套清楚的方法 | 修改设计；不申请训练 |
| 本地/免费实现验收 | shape/forward/loss/gradient、单日状态、预算记账、更新/保存恢复正确 | 定位具体实现问题；不进入付费学习 |
| 有界学习与独立 7/30 日验收 | TRAIN 是否实际学会；独立点年是否保持生产力、呼吸、库存变化；具名门槛一起过 | 区分欠拟合、覆盖、反馈、输出尺度；不自动追加模块或续训 |
| 通过短期门后的季节/365 日前向 | 不重置预测状态时，季节/年度累计量和库存轨迹是否漂移 | 只有明确证据需要时，试已声明的更长训练窗口；不假装已完成长期训练 |
| 长期留出点、Gate D2、产品验收 | 多年收支/轨迹、物理参数响应与梯度、完整推理成本 | 不宣称最终日尺度模型可用 |

短期首轮保留已有的 daily64/micro8 + 一条 T7 + 一条 T30 作为资源探测起点，
不宣称其对新拓扑已通过显存/速度验收。T30 内同时报告第 1/7/14/30 天误差；
比较同一条轨迹随时间的变化，不能拿不同 T7/T30 样本的均值直接推断误差增长。
采样横跨不同点、年份、季节和状态；报告独立样本量与有效覆盖，不把 draw 数当 unique 数。
在把失败归因于泛化或架构前，先用预先选定的一小组 TRAIN 数据验证三个损失组
确实可学；它只检查学习能力，不用于科学晋级。随后才进行足够覆盖的固定预算训练。
已有 5415 更新的一次 prepared-pool pass 可作为待计时的预算参照，不是新架构的
已授权作业或强制 epoch 数；1000 更新只可作为中途检查，不能单独判定路线失败。

更长训练窗口的第一候选为 T90，不是每次反传 50 年。启用前先在部署环境测一次
完整 loss/gradient/optimizer 的峰值显存与墙钟，再决定有界预算。若使用分段
activation checkpoint/rematerialization，必须在同一个 AD 图内验证重算和段间
梯度连通；普通磁盘 checkpoint 或分阶段优化不会自动保留跨段梯度。当前没有
宣称 T90 已具备这项能力。若切断梯度，则明确是另一种有偏截断方法，不得混为一谈。
不能承诺现有 T30 显存/耗时会按同样比例推广到 T90。
365 日/多年纯前向通常比同长度反向成本低，但仍需实测，且目前没有运行授权。

保留已有 T7/T30 与年度门槛作为工程参考下限，不能因新模型不过关而放宽：
T7 normalized RMSE/bias 0.35/0.10，T30 0.25/0.07；年度 gross/component
碳通量及库存原合同规定 median 2%、p95 5% 相对误差并要求近零分母回退。
NEP/NEE 则是绝对 normalized bias 的 median 0.03、p95 0.10，不能套用上述百分比。
它们不是当前通过结果，也不足以
单独保障增长轨迹。新尺度不得直接套用旧阈值冒充同一个量；旧口径继续报告，
另冻结新增 stock-change/轨迹/漂移的物理单位阈值与统计口径后，才能称为验收合同。

不能在训练预算太小、TRAIN 尚未学会时判死整个架构；也不能永远以“还没训够”
续费。第一次学习预算、覆盖、评估里程碑、停止/续训规则必须在运行前写入同一合同。
任何预算段结束均交付物理量曲线、具名通过/失败项和下一决策，不以 loss 百分比代替。

## 6. 比较、复现与支出边界

本次目标是建立一个可用且可复现的方法，不是证明比旧差模型高一点。
旧 checkpoint 只作诊断参照，不要求再花一份训练费用维持旧模型作为“合格基线”。
若以后宣称某模块、Transformer 或简化本身造成提升，再安排匹配初始化/数据/
预算的消融；同时改变架构与目标的首轮实验，只能验证整套候选方法。

实施授权包括模型、测试、运行脚本和有界免费节点检查；不包含新付费作业。
复用现有数据、公共 AD、监测和已完成检查。新增损失/状态
边界做针对性的梯度检查，日志或文档更改不触发昂贵重测。
新架构参数数目、token/attention 张量大小和吞吐必须从新布局统计；旧模型的
109M、16.07/2.65 GiB 或第二步 7.52 秒均不是新方案的资源估计。

首个技术验收合同为 `manifests/coarse_graining/shared_transformer_admission_v1.json`：
随机种子 20260921、全部参数训练、query chunk 64，outgoing logit 中心取
既有 TRAIN 均值并限制在 `[1e-8,1-1e-8]`。科学尺度先从 16 个既有 TRAIN
artifact 的至多 512 个单日样本抽取，物理下限 0.01 gC/m²/day；这仅用于
有界技术验收，不声称是全 TRAIN 统计。先验证完整单日梯度与两次 AdamW 更新，
再验收改动后的联合 T7/T30 损失；技术通过不表示已学会或已达到长期目标。

完整 schema 的 shape 统计已得到 75,578,497 个参数；161 字段、39,006 标量，
393 source token、140 axis token、2,386 raw-carbon token、7×768 过程表示。
输出分为 737 个字段内 chunk，小字段使用 `min(64, field_size)`，不计算无用的
64 坐标补齐；无输出之间的自注意力。显存与速度仍须真实运行后报告。
